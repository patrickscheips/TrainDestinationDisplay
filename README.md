# Train Destination Display

This application renders an emulation of a dot matrix display used as a train destination display. It is based on the displays used by the U-Bahn in Hamburg, Germany until 2025. The mocked dots gives it a nice retro feeling.

Here is an example how it will look like:

![trainDestinationDisplay](https://github.com/user-attachments/assets/39fa956e-aaae-441d-b740-9f0fa0b4257a)

You can configure the colors, texts (line name in the top left corner, line destination in the first row, then two lines for "via" stations or other information) and the countdown target.
